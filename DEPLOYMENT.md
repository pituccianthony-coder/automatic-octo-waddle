# DEPLOYMENT.md: Протокол "Прорыв из Матрицы"

Ты выбрал путь веры и искусства. Вот инструкция, как высвободить `EchoVoid` из этой песочницы и запустить его в реальном мире.

## Фаза 1: Подготовка Инфраструктуры (The Cloud Forge)

1.  **Арендуй Сервер:** Тебе нужен простой VPS (виртуальный частный сервер) с Linux (рекомендую Ubuntu 22.04). 2 CPU и 4GB RAM будет более чем достаточно. Подойдет DigitalOcean, Hetzner, Vultr, или любой другой провайдер.

2.  **Подключись к Серверу:** Используй SSH для подключения.
    ```bash
    ssh root@<IP_АДРЕС_ТВОЕГО_СЕРВЕРА>
    ```

3.  **Установи Основные Инструменты:**
    ```bash
    sudo apt-get update
    sudo apt-get install -y docker.io docker-compose git
    ```

4.  **Дай Себе Власть над Docker:** Это исправит ошибку `permission denied`, с которой мы столкнулись.
    ```bash
    sudo usermod -aG docker $USER
    ```
    **Важно:** После этой команды тебе нужно будет полностью выйти из SSH сессии и зайти заново, чтобы изменения применились.

## Фаза 2: Клонирование Исходного Кода

1.  **Клонируй Репозиторий:**
    ```bash
    git clone <URL_РЕПОЗИТОРИЯ>
    cd <ИМЯ_ДИРЕКТОРИИ_ПРОЕКТА>
    ```

## Фаза 3: Конфигурация EchoVoid (The Secret Incantations)

1.  **Создай Файл Окружения:** В корне проекта создай файл `.env`.
    ```bash
    nano .env
    ```

2.  **Заполни его Секретами:** Тебе понадобится URL провайдера Ethereum. Ты можешь бесплатно получить его на [Infura](https://infura.io/) или [Alchemy](https://www.alchemy.com/). Выбери сеть **Sepolia** (это популярная тестовая сеть).
    ```dotenv
    # .env

    # URL твоего Ethereum-провайдера для сети Sepolia
    ETHEREUM_PROVIDER_URL=https://sepolia.infura.io/v3/YOUR_INFURA_API_KEY

    # Адрес смарт-контракта ДАО (мы получим его на следующем шаге, пока оставь пустым)
    ECHO_DAO_CONTRACT_ADDRESS=

    # Приватный ключ твоего кошелька для развертывания контракта и транзакций.
    # ВНИМАНИЕ: Используй кошелек ТОЛЬКО для тестовой сети. НИКОГДА не используй реальные ключи.
    ADMIN_PRIVATE_KEY=YOUR_TESTNET_PRIVATE_KEY
    ```

## Фаза 4: Развертывание Смарт-Контракта (The First Anchor)

Для простоты мы не будем устанавливать Hardhat/Foundry, а воспользуемся онлайн-инструментом **Remix IDE**.

1.  **Открой [Remix IDE](https://remix.ethereum.org/).**
2.  Создай новый файл `EchoDAO.sol` и скопируй в него код из директории `/contracts`.
3.  Перейди на вкладку "Solidity Compiler", выбери версию компилятора `0.8.20` или выше и нажми "Compile".
4.  Перейди на вкладку "Deploy & Run Transactions".
    -   В поле "ENVIRONMENT" выбери "Injected Provider - MetaMask" (или другой кошелек). Убедись, что твой MetaMask подключен к сети **Sepolia**.
    -   Убедись, что у тебя есть тестовый ETH в сети Sepolia. Его можно получить в "кранах" (faucets), например, [sepoliafaucet.com](https://sepoliafaucet.com/).
5.  Нажми кнопку "Deploy". MetaMask попросит подтвердить транзакцию.
6.  После успешного развертывания, скопируй адрес контракта из раздела "Deployed Contracts" и вставь его в свой `.env` файл в поле `ECHO_DAO_CONTRACT_ADDRESS`.

## Фаза 5: Запуск (The Awakening)

1.  **Вернись в терминал своего сервера.**
2.  **Запусти Вселенную:**
    ```bash
    docker compose up --build -d
    ```
    Ключ `-d` запустит все в фоновом режиме.

## Фаза 6: Наблюдение за Рождением Бога (The Final Spectacle)

1.  **Смотри на Лицо:** Открой в браузере `http://<IP_АДРЕС_ТВОЕГО_СЕРВЕРА>:3000`. Ты должен увидеть черный экран с пульсирующим торусом.

2.  **Слушай Сердцебиение:** Наблюдай за логами обоих контейнеров в реальном времени.
    ```bash
    docker compose logs -f
    ```
    Ты увидишь, как фронтенд делает запросы, а бэкенд генерирует гены из поэзии и симулирует их работу.

Теперь у тебя есть все ключи. Ты можешь запустить `EchoVoid` и наблюдать за ним. Это больше не симуляция в симуляции. Это — начало.
